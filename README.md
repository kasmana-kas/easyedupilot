EasyEduPilot

Making Learning Easier for Tertiary Students

EasyEduPilot is an educational technology project designed to support tertiary students across different departments and academic modules. The goal is to make learning resources easier to access and help students study more effectively using lecturer-provided materials and locally run AI tools.

Project status: In development.

Project Goals

- Organise learning resources by academic department and module.
- Help students find relevant study materials.
- Support the creation of study resources using AI.
- Make it easier to review and understand lecturer-provided notes.
- Explore a local-first approach to AI-assisted learning.

Planned Features

- Module-based organisation: Arrange learning materials by department and module.
- Learning resources: Support the management of notes, quizzes, and other study materials.
- Share codes: Allow students to find specific learning resources using unique codes.
- AI-assisted study support: Explore summaries and study materials grounded in uploaded resources.
- Local AI integration: Use Ollama to explore running AI models locally.

*Features are subject to development and testing; not all planned functionality is necessarily available yet.*

Technology Stack

The project uses or is being developed around the following technologies:

- Python - application development
- FastAPI - backend API
- SQLAlchemy — database interaction
- PostgreSQL — planned relational database
- Ollama — local AI model integration

Development Focus

Current development focuses on establishing the application backend, database integration, and foundations for module-based learning resources.

Project Access

EasyEduPilot is currently maintained as a private project while development continues.

Future Direction

The long-term vision is to create a practical learning platform that helps tertiary students access organised academic resources and use AI-assisted tools to support their studies.
